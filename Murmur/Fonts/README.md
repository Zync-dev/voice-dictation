Static font files bundled with the app, downloaded from Google Fonts. All three families are licensed under the SIL Open Font License 1.1, which allows bundling and redistribution with software.

| Family | Files | Used for |
| --- | --- | --- |
| Bricolage Grotesque (48pt optical size) | SemiBold, Bold | Headlines, numbers, the wordmark |
| Figtree | Regular, Medium, SemiBold | All other text |
| JetBrains Mono | Regular, Medium | Keycaps and app names |

The Bricolage files are seen by WPF as the family "Bricolage Grotesque 48pt 48pt" (the size is doubled in the file's name table); `App.xaml` refers to it by that exact name.
